# Validation change record — 2026-10-12

## Issues documented before modification

1. Pads 1, 40, and 41 were rectangular. This reproduced the first contact of WeAct connectors P2, P1, and P3, but did not unambiguously identify the library's global Pin 1. The official pinout confirms pad 1 = PB12, pad 40 = 5V, and P3.1 = 3V3. The footprint convention was changed so that only pad 1 is rectangular; pads 40 and 41 are circular. No nets, coordinates, drill diameters, copper diameters, or pad numbers were changed.
2. `F.SilkS` had no explicit Pin 1 indicator. A triangle pointing only to pad 1 and a `1` label were added to both `F.SilkS` and `F.Fab`, outside the copper area.
3. The locally supplied STEP used CRLF line endings, while the file at the pinned official commit used LF. Their content was equivalent after line-ending normalization. The local validation copy was replaced with the exact upstream bytes; geometry was not modified.
4. The validation PCB did not contain every `F.Fab` primitive from the final footprint. Its footprint instance was synchronized with the library.
5. The distributable footprint now uses `${WEACT_BLACKPILL_KICAD_LIB}` for the 3D model path. The minimal validation PCB uses `${KIPRJMOD}/../3dmodels`, so it opens without that global variable after the STEP is downloaded.
6. Earlier documentation claimed prior ERC/DRC results without including machine-readable reports. Those claims were replaced with reports regenerated during this review.
7. DRC schematic-parity checking initially found 44 pads without the no-connect nets generated by the schematic and a description mismatch. The exact KiCad-generated no-connect net names were added to the minimal PCB without changing signals. The Pin 1 label was increased to 0.80 mm to satisfy the standard DRC text-size constraint.

## Numbering

No numbering changes were made. Pads 1–20 map to P2.1–P2.20; pads 40–21 map to P1.1–P1.20; pads 41–44 map to P3.1–P3.4. Numbers 41–44 are a documented convention of this library traced to the official SWD connector; they are not perimeter numbers published by WeAct Studio.

WeActStudio/WeActStudio.MiniSTM32F4x1 commit `05380f5c41f38eea8966a81c5acdeb7512cd909f`, including the V3.1 schematic, mechanical drawing, STEP model, hardware notes, and published pinout.
